# III.17 反歧视和反霸凌

本章原作者：杜超瑜、江睿恒、曹臻心2024年08月28日校对：杨锦涛

# 1. ETH

ETH有着严格的Respect Code，内容包括反歧视、反性骚扰、反霸凌和反暴力与胁迫、反学术不端，并提供对受害人的帮助和支持，详情可见：[Code of Conduct “Respect”](https://ethz.ch/students/en/campus/eth-culture-and-values/living-respect/code-of-conduct.html)

此外，ETH任命了调解员（ombudspersons）和信任人员（confidants）来帮助有困难的ETH成员。调解员负责处理冲突以及对非法行为的举报，确保保守机密性。信任人员专门处理研究诚信和不当行为问题，提供指导并保持机密性。具体请参考：[Ombudspersons and trusted intermediaries](https://ethz.ch/en/the-eth-zurich/organisation/ombudspersons-and-trusted-intermediaries.html)

# 2. UZH

UZH有着严格的社会责任（Social Responsibility）政策，其中包括领导与管理、多样性、性别政策、残疾人机会平等、反性骚扰，并提供对受害人的帮助和支持，具体请见：[Social Responsibility](https://www.uzh.ch/cmsssl/en/explore/basics/responsibility.html)

# 3. 关于学术公正

学术公正指的是在学术领域中确保研究、评审和教学过程公正、透明的原则；涵盖研究道德、同行评审、资源分配、教学公正和知识传播等方面。目的是维护学术活动的诚信和可信度，且对科学的长期成功至关重要。 如果你在研究或学术工作中遇到与学术公正和伦理有关的问题，可以首先查阅学校的准则和指南，以获取有关如何处理问题的信息和建议。如果问题仍然存在，可以考虑咨询你所在机构的研究伦理专家或相关委员会以获取更多帮助。具体参见：[ETH - Scientific integrity](https://ethz.ch/en/research/ethics-and-animal-welfare/research-integrity.html)

# 4. 更多支持渠道

- ETH的学生可以通过右侧链接了解各类咨询渠道：[ETH - Advice](https://ethz.ch/students/en/counselling.html)
- UZH的学生可以通过右侧链接了解各类咨询渠道：[UZH - Advice](https://www.students.uzh.ch/en/advice.html)
- VSETH Help: [VSETH Help](https://help.vseth.ethz.ch/)总结了紧急情况支持、心理咨询和帮助、以及尊重与反霸凌反歧视的渠道。此外，VSETH Helpdesk志愿者可以提供个人化的咨询和帮助：[VSETH Helpdesk](https://help.vseth.ethz.ch/helpdesk)
- SpeakUpETH：[SpeakUpETH](https://speakup.vseth.ethz.ch/)是VSETH在AVETH的支持下于2021年春季学期在苏黎世联邦理工学院启动的一个项目。该项目旨在通过展示学生、教职员工和校友的证词和经历，突出苏黎世联邦理工学院的歧视和不当行为案例，以提高人们对这些问题的认识。SpeakUpETH还将为希望分享自己故事的学生提供支持，引导它们获得相关服务，并为大家提供一个联络点。
- 瑞士危机预防中心（KIZ）：困境和危机是不可预测的，但是，必须迅速采取行动，并进行仔细考虑。瑞士危机预防中心为决策者和受影响者提供专业和高质量的支持。其个人咨询服务可参考：[Privatpersonen - Krisenintervention Schweiz](https://kriseninterventionschweiz.ch/privatpersonen/)，请注意可能产生的咨询费用。
- 哥大MAE中国学联联系了一些医院搭建了一个针对留学生的免费/低价心理咨询平台，可关注FOR STORY公众号
