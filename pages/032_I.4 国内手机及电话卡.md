# 1. 最低月费保号套餐

目前，国内三大运营商最低的月租套餐是：

- 中国电信：电信5元无忧卡
- 中国移动：8元套餐 分为语音版和流量版，部分地区只有不包括通话流量的8元飞享套餐
- 中国联通：联通8元流量王

| --- | --- | --- | --- |
| 月租 | 5元 | 8元 | 8元 |
| 客服电话 | 10000 | 10086 | 10010 |
| 套内 | 200M国内流量 | 30分钟通话或100M国内流量 | 30分钟通话或200M国内流量 |
| 套外流量 | 1G内：0.02元/M | 0.29元/M，累计10元免费使用至100M，累计30元免费使用至1G | 10元/G |

| 5G以上：0.005元/M |  |  |  |
| 套外语音 | 0.1元/分钟 | 0.19元/分钟（部分省份为0.25元/分钟） | 0.15元/分钟 |
| 套外短信 | 0.1元/条 | 0.1元/条 | 0.1元/条 |

想改保号套餐的可直接关注移动/电信/联通官方公众号，找到人工客服（也可公众号直接打字人工客服发送）要求更改对应套餐。

其他如果手机套餐绑定了宽带，需要带上身份证（和供应商提供的路由器）去营业厅先办理解绑，再办理最低保号套餐。具体可人工咨询或咨询当地营业厅。

最好预充足够费用（按年计，出国多少年就充多少钱），或设置支付宝按月自动充值，以便运营商每月能顺利扣费。若选择支付宝，微信随用随充，应确保账户余额充足，避免由于遗忘等原因导致手机号长期欠费被销号。

# 2. 国际漫游

三大运营商漫游业务均至瑞士，开通国际漫游业务可通过人工客服或者点击相关公众号服务开通，具体资费情况（如电话，短信，流量，日收费上限等）可查看官方公众号及网页。

- 中国移动（境外国漫服务专线：+86 138 0010 0186 或 +86 10086）： 
  
  - 漫游公众号：中国移动国际漫游（开通漫游，多种流量及长途业务办理，业务资费等）
- 中国联通： 
  
  - 漫游公众号：中国联通（点击链接到网上营业厅，左侧栏国际漫游）
  - 境外漫游服务专线：+86 18618610010

- 中国电信： 
  
  - 漫游公众号：中国电信国际及港澳台漫游（开通漫游，流量包办理，资费查询等）
  - 境外漫游服务专线：+86 18918910000

对于所有运营商用户，务必在离境前办理好国际漫游业务，离境后办理会很麻烦。境外漫游流量计费一般有按天封顶，如瑞士境内的电信流量为25元/天封顶，按北京时间的0点计算一天（不是从开始使用时计24小时）。

# 4. 关于苹果手机的App Store区域问题

对于使用苹果手机人员，抵达瑞士前需将苹果手机及App Store区域切换到瑞士，以便能够在App Store中搜索并下载瑞士常用的各类应用（如[SBB Mobile](https://www.sbb.ch/de/fahrplan/mobile-fahrplaene/sbb-mobile.html)、[ZVV-App](https://www.zvv.ch/zvv/de/service/apps/zvv-app.html)等）。

设置步骤（根据手机具体型号可能略微有所不同，仅供参考）：

Apple Setting：Setting → Language & Region → Region Apple Store：Apple Store → Profile Picture (Up Right) → Profile ID (Apple ID) → Country / Region

亦可选择新增一个Apple账户，在需要使用不同版本的App Store时切换账户即可。

# 5. 关于安卓手机的谷歌框架

【学联提醒】受国际局势影响，部分新款的国产安卓手机可能无法使用任何谷歌服务，此时建议更换其他手机以确保在瑞士能够下载并使用相关软件。

对于使用安卓手机人员，因瑞士许多手机软件均依赖谷歌框架运行，入境瑞士前需开启安卓手机内的谷歌基础服务，以便于通过Google Play Store安装瑞士生活常用的APP（如[SBB Mobile](https://www.sbb.ch/de/fahrplan/mobile-fahrplaene/sbb-mobile.html)、[ZVV-App](https://www.zvv.ch/zvv/de/service/apps/zvv-app.html)等）并运行之。为此，最好在国内即安装好所谓的“谷歌三件套”（Google Service Framework、Google Play Service、Google Play Store）。此外，Google Play Store也需要用户正确设置所在国家和地区。

可在B站或知乎等平台查询教程自行安装，或通过淘宝购买远程协助安装，但需甄别部分黑心店家。
