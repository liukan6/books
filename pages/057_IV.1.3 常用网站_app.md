# IV.1.3 常用网站/app

本章原作者：王尊2025年04月19日校对：高吉洋

本章节最近校对于：2025年04月19日

# 1. [myStudies](https://www.lehrbetrieb.ethz.ch/myStudies/login)

myStudies（校方简介见：[myStudies Introduction](https://ethz.ch/students/en/studies/academic-support/web-based-platforms/mystudies.html)）可能是你在ETH最重要的网页了，你需要在上面完成很多事情，比如注册新学期、注册课程、注册考试（见下）、更新个人信息等。相关的细节以及个人登录信息应该已经或将要通过电邮发送给新生了，请按照指示完成更改密码等一系列操作。 （2023年新规定，学期注册证明改为电子版，不再邮寄实体文件；暂不清楚新生是否会收到实体的学期注册证明）

> 参考：关于myStudies
> 
> - myStudies的登陆以及学期注册：[https://ethz.ch/content/dam/ethz/main/continuing-education/Merkblaetter/Login_Einschreibung2021.pdf](https://ethz.ch/content/dam/ethz/main/continuing-education/Merkblaetter/Login_Einschreibung2021.pdf)

# 2. [Moodle](https://moodle-app2.let.ethz.ch/auth/shibboleth/login.php)

Moodle是ETH使用的学习资料发布平台（有网页端，手机/平板电脑app供选择），讲师的笔记、教案等资料都会在此上传，许多作业也需要从这里下载并在这里完成、提交。该平台的登录信息与myStudies相同，按相关邮件指导执行即可。一般来说你在mystudies上注册课程之后，如果该课程有Moodle网页，则你会被自动加入该Moodle网页。

# 3. EduApp

EduApp也是较为常用的app，主要用于课表查看、信息查询、课上互动等，现在部分课程会使用在EduApp上的clicker作为课堂思考题的作答程序。

# 4. Mensa（菜单查看）

人是铁饭是钢，既要好好学习，更要好好吃饭，我们推荐下载一个查看食堂菜单的app，可以在应用商店里搜索”ETH & UZH Mensa“之后选择一款。（更多同学反应UZH的食堂更好吃一点）

# 5. ETH VPN (Cisco Secure Client)

ETH提供校园网VPN，介绍详见 [VPN - IT knowledge base](https://unlimited.ethz.ch/spaces/itkb/pages/21125994/VPN)，使用cisco secure client，并使用ETH的网络账号密码登录后，可以在校外访问内网资源。
