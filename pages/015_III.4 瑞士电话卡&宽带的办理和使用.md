# 2. 关于预付卡（Prepaid）和合约卡（Postpaid）

瑞士电话卡分为Prepaid Card（预付卡）和Postpaid Card（合约卡），目前瑞士约80%的用户均为Postpaid Card（合约卡）。

两种电话卡各有千秋。Prepaid卡和国内的电话卡模式类似，先充值后使用，如果余额不足，服务便会被终止。

- Prepaid卡缺点是相同服务下，Prepaid的价格通常会比Postpaid卡贵，且套餐选择种类较少。
- Postpaid卡一般会有丰富的套餐选项，且价格吸引人。对于Sunrise及其子品牌，Postpaid卡仅针对在瑞士合法居留的人，即收到居留卡（permit）后才能申请。

在瑞士，两种电话卡均需实名才能购买。

|  | 优点 | 缺点 |
| --- | --- | --- |
| Prepaid | 只需护照即可购买适合刚来瑞士还没拿到permit的同学 | 价格偏贵，套餐偏少需要预付费 |
| Postpaid | 套餐丰富，性价比高（拿到permit后尽快转Postpaid） | 有permit才能申请 |

本表为Sunrise及其子品牌规定，其它运营商规定请自行查询

# 4. 瑞士宽带基本情况介绍

在瑞士，家庭宽带一般有三种技术选项：

- 5G上网盒（Home 5G）：连接到5G无线基站，类似手机热点，但连接稳定性、最大连接设备量以及每个设备的通信带宽优于开手机热点。5G上网盒的整体通信质量略低于有线/光纤网络
- 有线网络（Home Cable）：通过有线电视网提供互联网，速度稳定但通常比光纤略低，适合家庭常规使用
- 光纤网络（Home Fiber）：光纤是目前最快最稳定的接入方式，传输速度高、延迟低，适合高带宽需求的用户

每个住址的通信设施覆盖情况不一样，比如说，有的住址只有5G上网盒选项，而有的住址5G信号覆盖弱，不推荐上网盒，但可选有线网络和光纤网络。因此，可以办理的具体技术选项和套餐价格需要根据具体地址来确定。

## 4.3 Sunrise Yallo家庭宽带

在瑞士找到长期住址后，如果你希望办理家庭宽带，可以在通过下方小程序码提交宽带预约后，在群内咨询开卡员同学。开卡员同学将私信联系你，并查询你所在住址的可用技术选项，提供全部套餐报价供你选择。如果看到了中意合适的套餐，请告知开卡员同学，它将为你线上操作完成办理，操作期间需要你在线签字确认。

请留意，宽带合约为2年固定期限，2年后才可以取消。我们推荐在满足以下三项条件后：

1. 在瑞士停留时间不短于2年；
2. 租房合同期限不低于2年或无期限限制；
3. 两年内不会搬家

再考虑办理宽带。宽带一般有99瑞激活费，但在一些促销活动期间可能免去激活费。学联将在Sunrise YOL福利群中及时发布各种促销信息，可以多多留意。
