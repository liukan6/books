# III.16 心理健康

本章原作者：杜超瑜、江睿恒、曹臻心2024年08月28日校对：杨锦涛

【学联提醒】学校的心理咨询中心提供的是心理咨询，而不是心理或神经科治疗。如果需要专业的治疗，可以通过学校的心理咨询中心寻找心理医生进行治疗。

# 1. 常见心理咨询渠道

## 1.1 ETH&UZH心理咨询服务

ETH与UZH为在读的同学们提供免费的心理咨询服务，每次的心理咨询时长为50分钟左右，语言可选择德语或英语。具体可参考：[ETH&UZH: Psychological Counseling Services](https://www.pbs.uzh.ch/en.html)。

## 1.2 Nightline Zurich

[Nightline](https://www.nightline.ch/public/en/home/)是一个由学生为学生免费运营的心理支持热线服务。该项目由学生志愿者组成，通过匿名电话热线和文字聊天，提供倾听、共情和心理疏导服务，为学生创造一个安全的情绪释放渠道。支持语言：英语、德语、法语、意大利语。Nightline内容包括：

- 匿名邮件服务：学期和假期期间均开放，每天晚上20:00至次日00:00
- 匿名在线实时聊天：学期和假期期间均开放，每天晚上20:00至次日00:00
- 匿名电话热线：仅在学期期间开放，每天晚上20:00至次日00:00

## 1.3 苏村留声机

苏村留声机是由苏黎世学联设立的一个心灵驿站，旨在关怀和支持在苏黎世留学的中国学生群体，关注他们的身心健康。平台通过和学生做匿名聊天室访谈、接收匿名留学生生活投稿、组织治愈类活动，并设立匿名倾诉渠道等，力求为同学们带来更多温暖。详情请关注苏黎世学联公众号。项目内的“苏村治愈树洞” 情感倾诉渠道为：

- 发送微信消息至微信号：xueliansuliya
- 发送邮件至树洞邮箱：[gagasuliya@gmail.com](mailto:gagasuliya@gmail.com)

留声机志愿者会认真倾听并且回复。我们承诺，所有交流内容将严格保密，不会透露给任何第三方。

## 1.4 瑞士143

[143.ch](http://143.ch)是一家瑞士全国范围内的心理帮助与自杀预防的专业志愿组织，提供在线聊天、电话和邮件渠道的帮助服务，并且支持英语。请留意，如果需要英语电话服务，请拨打080014300，而不是直接的143（直接拨打143会接入德语/法语/意大利语服务）

# 2. 心理治疗

在校外接受治疗时需区分精神科医生（psychiatrist） 和心理医生（psychologist）：前者可以开处方药，后者不可。目前苏黎世大多数诊所同时有精神医生和心理医生，如果同学实在不确定，可以通过学校的心理辅导中心预约医生，或在就诊前让诊所或主治医生打电话给保险公司确认。

目前瑞士的基础医保覆盖了心理治疗，但仍然需要先有医生的处方（例如精神科医生）。
